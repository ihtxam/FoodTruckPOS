Chaslay merchant admin

Full admin panel is coming next. For now, use SSH on your server:

Create a merchant

docker compose exec api npm run create-tenant -- --slug=client-name --name="Shop Display Name"

This prints a unique POS API key for that merchant. Put it in the Android app as SYNC_API_KEY.

Online shop URL

https://shop.chaslay.com/client-name

License code

docker compose exec api npm run generate-code -- --tenantSlug=client-name --deviceId=DEVICE-UUID --days=365

API docs: api.chaslay.com/health
